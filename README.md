# RPG de HP: O jogo

Aventura de fantasia em 3D para navegador, com seleção de personagens, exploração, feitiços, inimigos que perseguem o jogador, vida, energia mágica, níveis e controles adaptados a celular e computador.

## Como jogar

- Abra `index.html` em um navegador com acesso à internet.
- Escolha um personagem e toque em **Entrar no mundo mágico**.
- Computador: use **WASD** ou as setas para andar, **Espaço** para pular e **E** ou clique na tela para lançar feitiços.
- Celular: use os botões na tela.

## Publicar na Vercel

Importe este repositório na Vercel como um projeto estático. Não é necessário comando de build nem diretório de saída: o arquivo `index.html` fica na raiz.

## Tecnologias

- HTML, CSS e JavaScript
- Three.js via CDN (requer internet)

## Créditos e observação

Projeto de fã, não oficial e sem vínculo com Warner Bros. ou titulares de Harry Potter. Os personagens e o universo são inspirados na franquia; o protótipo usa modelos geométricos criados por código, não modelos oficiais ou retratos realistas.
